Critical constraints:
- Money fields: bigint (paise), currency char(3) default 'INR'
- hrms_employees.status check in ('probation','confirmed','transferred','suspended','separated')
- hrms_employees.employee_type check in ('permanent','temporary','contract','deputation')
- hrms_leave_apps.status check in ('draft','pending','approved','rejected','cancelled')
- payroll_runs: status check in ('draft','processing','approved','disbursed','failed')
- payroll_slips: net_pay_minor bigint computed from components (stored)
- payroll_pf: employee contribution 12%, employer 12% of basic (configurable)

## Step 2 — CQRS routes + consumers
Employee:
  POST /hrms/employees                 → hrms.employee.create
  PATCH /hrms/employees/:id/confirm    → hrms.employee.confirm (probation → confirmed)
  PATCH /hrms/employees/:id/transfer   → hrms.employee.transfer
  PATCH /hrms/employees/:id/separate   → hrms.employee.separate
  GET  /hrms/employees/:id             → cache → repo

Leave:
  POST /hrms/leave-types               → hrms.leave_type.create
  POST /hrms/leave-allocations         → hrms.leave.allocate (annual allocation)
  POST /hrms/leave-applications        → hrms.leave.apply
  PATCH /hrms/leave-applications/:id/approve → hrms.leave.approve
  GET  /hrms/leave-applications?empId= → cache → repo

Attendance:
  POST /hrms/attendance                → hrms.attendance.mark (bulk allowed)
  GET  /hrms/attendance?empId=&month=  → cache → repo

Recruitment:
  POST /hrms/job-openings              → hrms.job.create
  POST /hrms/applications              → hrms.application.create
  PATCH /hrms/applications/:id/offer   → hrms.application.offer

Payroll:
  POST /payroll/structures             → payroll.structure.create
  POST /payroll/runs                   → payroll.run.create (month + department)
    Consumer: calculate salary slips for all employees in dept, write payroll_slips
    After approval → emit payroll.run.approved → finance-service posts to GL
  PATCH /payroll/runs/:id/approve      → payroll.run.approve
  PATCH /payroll/runs/:id/disburse     → payroll.run.disburse (EFT to employee bank)
  GET  /payroll/slips/:id              → cache → repo

Loans:
  POST /payroll/loans                  → payroll.loan.create
  PATCH /payroll/loans/:id/disburse    → payroll.loan.disburse
  GET  /payroll/loans?empId=           → cache → repo

## Step 3 — Domain rules
- Leave balance: approved leave debits hrms_leave_allocs.balance_days
- Payroll calculation in domain.ts (pure): basic + allowances - deductions = net
- Statutory: PF = 12% of basic, TDS = computed per slab (simplified: 10% above 500000 annual)
- Payroll run only for confirmed employees (not probation)
- Separation triggers leave encashment computation and gratuity calculation

## Step 4 — Events
payroll.run.approved  → finance-service (GL posting: debit salary expense, credit bank)
hrms.employee.created → notification-service (welcome email)
hrms.leave.approved   → notification-service (employee + approver)
payroll.loan.disbursed → finance-service (GL: debit advance, credit bank)

## Step 5 — Tests
- Leave balance deduction: apply leave → balance decreases; reject → balance unchanged
- Payroll calc domain: basic + HRA + DA - PF - TDS = net (pure, no DB)
- Payroll run state machine: draft → processing → approved → disbursed
- CQRS: POST /payroll/runs → SQS → consumer → DB (MemoryQueue + MemoryCache)
