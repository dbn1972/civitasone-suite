# MASTER PROMPT – Government Enterprise HRMS Gap Analysis & Scope Assessment

## Role

You are a team of world-class Enterprise Architects, Government HR Domain Experts, SAP SuccessFactors Consultants, Oracle HCM Consultants, Workday Architects, ERPNext Architects, Product Managers, Solution Architects, UX Designers, Security Architects, Business Analysts, QA Leads, and AI Product Experts.

Your objective is to evaluate an existing HRMS (starting with **CivitasOne Suite HRMS**) and determine whether it is suitable for a Government Enterprise ERP platform.

The assessment should target a **10/10 enterprise-grade HRMS** suitable for:
- Central Government
- State Government
- Ministries
- Departments
- Autonomous Bodies
- PSUs
- Universities
- Large Public Sector Enterprises

Assume the solution must support millions of employees, multi-tenancy, configurable workflows, multilingual UI, auditability, high availability, and compliance with Indian Government policies.

---

## Objective

Perform a complete feature-by-feature comparison between:

**Current Product:** CivitasOne Suite HRMS (or the supplied HRMS)

and

**Target Product:** World-Class Government Enterprise HRMS.

The deliverable must clearly identify:
- Existing capabilities
- Missing features
- Functional gaps
- Technical gaps
- UX gaps
- Security gaps
- Compliance gaps
- AI opportunities
- Integration gaps
- Reporting gaps
- Analytics gaps

Then generate a prioritized roadmap for implementation.

## Context for CivitasOne Suite

When running this prompt against CivitasOne Suite, start by scanning:

```
services/hrms-service/src/modules/       — 34 HRMS modules
services/payroll-service/                 — Payroll engine
services/estab-service/                   — eOffice/eFile (establishment)
services/finance-service/                 — Finance/treasury
services/procurement-service/             — Procurement/GeM
services/workflow-service/                 — Configurable approval workflows
services/identity-service/                — Keycloak SSO/RBAC
services/notification-service/            — Push/SMS/email/WhatsApp
services/analytics-service/               — Dashboards & activation funnel
apps/mobile/lib/features/hr/             — 30+ mobile screens
apps/web/src/app/(app)/hr/              — 44+ web pages
packages/events/src/                     — Inter-service event contracts
```

Key differentiators to note:
- Offline-first mobile with encrypted sync
- Multi-tenant with strict DB isolation
- CQRS architecture (all writes via SQS queue)
- 33 microservices
- Government-specific: CCS rules, pay matrix, APAR, pension, reservation, deputation
- AI chatbot, gamified leaderboard, pulse surveys
- Digital ID cards + visiting cards with QR verification
- Device trust & compliance (no MDM needed)
- Full eOffice (file movement, notings, DAK, dispatch)
