## How to Use This Manual

- **New to CivitasOne?** Start with Chapter 01 — it walks you through your first login and the setup wizard.
- **Looking for a specific task?** Jump to the relevant chapter. Each one works on its own, so you can print just the pages you need.
- **Unsure about a word?** Chapter 12 (Glossary) explains every specialist term in one sentence.

## Conventions Used

| Convention | Meaning |
|-----------|---------|
| **Bold text** | A button name or screen title you'll see on your screen |
| `[Screenshot: description]` | Where an image would go in a printed version |
| > Blockquote | A tip or warning worth paying attention to |
| Numbered steps (1, 2, 3…) | Do these in order |
