# spikes/solver — ST-M01-13 allocation solver spike (D-ST-05, D-ST-22)

A throwaway, self-contained spike that measures the **TypeScript baseline**
(exact min-cost-flow per partition + a local-search pass) and the **OR-Tools
CP-SAT** candidate (Apache-2.0, sidecar) against the five pre-registered D-ST-05
thresholds (spec §7, §15, §16).

> **Not production.** This package is deliberately **outside** the pnpm workspace
> (`pnpm-workspace.yaml` covers only `apps/*`, `services/*`, `packages/*`). It is
> not imported by any service, is invisible to the CI architecture guards and
> secret scanner, and does not touch `pnpm-lock.yaml`. Install and run it in
> isolation with `npm`.
>
> **All data is SYNTHETIC**, generated by a seeded deterministic PRNG. There is
> **no real personal data**.
>
> **Timefold is NOT built or run** (D-ST-06 is PROPOSED, "before M01 spike"). Only
> the adapter interface slot is declared. See `REPORT.md`.

See `REPORT.md` for the PASS/FAIL findings against each threshold and the
recommendation.

## Run

```bash
cd spikes/solver
npm install                 # isolated; does NOT read pnpm-workspace.yaml

npm run typecheck           # tsc --noEmit
npm test                    # vitest property + validator + adapter tests

npm run determinism         # 3-run plan-hash determinism  -> bench-results/determinism.json
npm run bench               # 1k/10k/100k baseline timings  -> bench-results/benchmark.json

# CP-SAT (criterion 5): build the pinned sidecar image on a DEDICATED buildx
# builder, CVE-scan with trivy, smoke-test, then remove the image+builder.
# Guards disk at the 80% hard cap and aborts if exceeded.
bash scripts/docker-cpsat-build.sh bench-results

# Then benchmark/replay against the real sidecar:
npm run bench -- bench-results/benchmark.json \
  --cpsat "docker run --rm -i st-m01-13-cpsat:tmp"
```

## Layout

| Path | Purpose |
|---|---|
| `src/SolverPort.ts` | Technology-neutral port (interface) + Timefold slot (NOT RUN). |
| `src/generate.ts` | Seeded deterministic synthetic generator (no PII). |
| `src/feasibility.ts` | The single shared definition of structural hard constraints. |
| `src/scoring.ts` | Objective F(x) + canonical sha256 plan hash. |
| `src/mcmf.ts` | Exact integer min-cost max-flow. |
| `src/baseline.ts` | TS baseline (MCMF per partition + local search) — the default. |
| `src/cpsat.ts` | OR-Tools CP-SAT sidecar adapter (TS side). |
| `sidecar/solver.py` | Python CP-SAT sidecar (pinned ortools). |
| `sidecar/Dockerfile` | Small pinned throwaway image. |
| `src/validator.ts` | Independent validator (zero hard violations, zero dup occupancy). |
| `src/benchmark.ts` | 1k/10k/100k timings + validation. |
| `src/determinism.ts` | 3-run plan-hash determinism / replay harness. |
| `test/solver.test.ts` | Vitest property suite + negative controls. |
| `scripts/docker-cpsat-build.sh` | Dedicated-builder build + trivy CVE scan + smoke. |
| `REPORT.md` | D-ST-05 findings, PASS/FAIL, recommendation. |

## Architecture note

Host is **arm64 (aarch64)**. All timings in `REPORT.md` are from this host and
**must be re-run on x64 before the D-ST-05 final lock** (end of M01).
